## What I learned

- **Github:** A powerful platform that enables developers to host, track, and manage version control for their code repositories
- **README.md:** Acts as the homepage and primary documentation interface for a project.
- **MIT License:** A highly permissive legal notice that allows others to use, modify, and distribute your code with minimal restrictions.
- **virtual environment:** Separate, isolated safe spaces for individual projects to prevent package dependency conflicts.
  \_ **pip:** The standard package installer for Python. It acts as the delivery service that fetches libraries from the internet and installs them into your environment.
- **requirements.txt:** A simple text file listing all external Python libraries needed for the project. Paired with 'pip install -r requirements.txt', it guarantees that anyone can recreate your exact environment instantly.
- **.gitignore:** A configuration file used to explicitly tell Git which file or folders (like private keys, configuration files, or local virtual environments) should never be tracked or uploaded to GitHub.
- **The Git Workflow (Stage, Commit, Push):**
  _'git add' - Prepares and stages your modified files, telling Git exactly which changes you want to include in your next snapshot.
  _'git commit' - Saves your staged changes locally, creating a permanent dated snapshot of your progress accompanied by a short descriptive message.
  \*'git push' - uploads all of your local commits to your remote repository on GitHub, making your updated code visible to others and backed up in a cloud.
